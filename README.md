# Customer Segmentation Using K-Means Clustering

## Project Overview

This project uses customer demographic and behavioral data to identify distinct customer segments using **K-Means clustering**.

The goal is to transform raw customer data into meaningful segments that can support targeted marketing, customer personalization, and differentiated customer strategies.

The analysis focuses primarily on:

- Age
- Annual Income
- Spending Score

The final model assigns each customer to a cluster, creating a customer-level segmentation dataset that can be used for further analysis and marketing decisions.

---

## Files

- `data/`: contains processed CSV data files
- `notebooks/`: contains the Jupyter notebook used for analysis
- `main.py`: organizes project assets and creates the project README

---

## Usage

1. Place your customer dataset in the project root.
2. Run the script:
   ```bash
   python main.py
   ```
3. Review the notebook in the `notebooks/` folder and the generated `README.md`.
